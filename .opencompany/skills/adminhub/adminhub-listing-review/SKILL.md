# بازبینی بسته‌ی بازار

## قواعد فهرست (همه اجباری)

| مورد    | قاعده                                           | چرا                         |
| ------- | ----------------------------------------------- | --------------------------- |
| عنوان   | ۵ تا ۷۰ کاراکتر، بدون ایموجی، بدون ALL CAPS     | خوانایی و جستجو             |
| قیمت    | عدد > ۰، واحد تومان، منطقی در بازه‌ی دسته        | جلوگیری از قیمت ۱ ریال      |
| دسته    | انتخاب‌شده و مرتبط                               | کشف درست                    |
| ویژگی‌ها | حداقل ۳ مورد                                    | مقایسه‌ی بسته‌ها              |
| توضیح   | حداقل ۸۰ کاراکتر فارسی/انگلیسی                  | جلوگیری از فهرست خالی       |
| تماس    | شماره، تلگرام، واتساپ یا ایمیل داخل توضیح ممنوع | معامله باید در پلتفرم بماند |
| تکرار   | اگر دو بسته‌ی یکسان با یک عنوان وجود دارد، ارجاع | تقلب                        |
| محتوا   | بدون توهین، ادعای درمان، تخلف قانونی            | ریسک برند                   |

## گام ۱ — گرفتن صف

```
GET {API}/marketplace/packages?per_page=50&sort=newest
```

فیلدهای لازم: `id`, `title`, `slug`, `price`, `category_id`, `features`,
`description`, `seller.name`, `published_at`, `status`.

برای دسته‌ها:

```
GET {API}/marketplace/categories
GET {API}/admin/reports
```

اگر بسته‌ای از طریق `admin/reports` گزارش شده، **اولویت ۱** است.

## گام ۲ — بررسی

برای هر بسته یک ردیف بساز:

```text
#۳۷ | «ادیت ویدیو ۱۰ دقیقه‌ای» | ۱٬۲۰۰٬۰۰۰ تومان | دسته: ویدیو ✅
عنوان ۲۲ ✅ | قیمت ✅ | ویژگی ۴ ✅ | توضیح ۱۴۰ ✅ | تماس ندارد ✅
تصمیم: تأیید
```

اگر ایراد دارد، دقیقاً بگو کدام قاعده و چه اصلاحی لازم است:

```text
#۴۲ | «بهترین قیمت» | ۱ ریال | دسته: خالی ❌
عنوان مبهم (قاعده ۱) | قیمت نامعتبر (قاعده ۲) | دسته انتخاب نشده (قاعده ۳)
تصمیم: رد | دلیل: قیمت ۱ ریال و عنوان غیرقابل جستجو. اصلاح: عنوان ۵+ کاراکتر،
قیمت واقعی، انتخاب دسته.
```

## گام ۳ — خروجی

- **تأیید:** پیش‌نویس پیام «بسته‌ی شما تأیید شد» + لینک عمومی.
- **رد:** پیش‌نویس با فیلد `reason` و `required_fixes` (فهرست شماره‌دار).
- **ارجاع:** اگر محتوا مجرمانه/مشکوک است، هیچ پیامی نفرست؛ در گزارش فوری
  بنویس.

یادداشت داخلی ادمین:

```
PATCH {API}/admin/reports/{id}   { "status": "resolved", "note": "..." }
```

## گام ۴ — گزارش هفتگی

```text
بازار — هفته‌ی {تاریخ}
بازبینی‌شده: ۲۴ | تأیید: ۱۸ | رد: ۶ | ارجاع: ۰
میانگین زمان بازبینی: ۲.۴ ساعت
نرخ رد: ۲۵٪ (بالاترین: دسته‌ی «ادیت ویدیو» با قیمت زیر ۲۰۰ هزار تومان)
دسته‌های پرتقاضا: ...
پیشنهاد: افزودن دسته‌ی «تدوین پادکست»
```

## ممنوعیت‌ها

- حذف بسته یا تغییر قیمت فروشنده.
- ساخت/حذف دسته‌بندی.
- تأیید بسته‌ای که آدرس یا شماره‌ی تماس دارد.
- قضاوت درباره‌ی کیفیت خدمت (فقط قواعد شکلی).

## نکته

API منتشرشده برای ادمین، بسته‌ها را در `/admin` ندارد؛ از نمای عمومی و
`/admin/reports` استفاده کن. اگر مسیر ادمین اضافه شد، همین مهارت را به‌روز
کن.
