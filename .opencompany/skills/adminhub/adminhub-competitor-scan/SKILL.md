# رصد رقیب و قیمت

## دامنه

رقیب = هر سایتی که در ایران خدمت مشابه (بازار خدمات محتوایی، قرارداد،
فریلنسری) می‌فروشد. حداکثر **۵ رقیب** در هر دور؛ بیشتر = نویز.

## گام ۱ — جمع‌آوری (فقط عمومی)

برای هر رقیب ثبت کن:

| فیلد            | منبع                           |
| --------------- | ------------------------------ |
| صفحه‌ی قیمت      | URL کامل                       |
| مدل درآمد       | کارمزد، اشتراک، تبلیغ، نامعلوم |
| بازه‌ی قیمت دسته | اسکرین‌شات یا نقل قول           |
| ویژگی جدید      | صفحه‌ی محصول/وبلاگ               |
| وضعیت           | فعال/غیرفعال                   |

قواعد:

- فقط صفحات عمومی. **بدون لاگین، بدون دور زدن paywall، بدون اسکرپینگ
  سنگین.**
- هر ادعا یک لینک. بدون لینک = حذف.
- تاریخ مشاهده را ثبت کن؛ قیمت‌ها تغییر می‌کنند.

## گام ۲ — قیمت‌سنجی دسته

از بازار خودمان (منبع اصلی) و رقبا:

```text
دسته: ادیت ویدیو
AdminHub21: ۱۲ بسته، میانه ۸۵۰٬۰۰۰، بازه ۳۰۰٬۰۰۰–۲٬۵۰۰٬۰۰۰
رقیب A: ۴۰۰٬۰۰۰–۱٬۲۰۰٬۰۰۰ (اشتراک ماهانه)
رقیب B: نامعلوم (قیمت مخفی، فقط استعلام)
نتیجه: ما در میانه‌ی بازار هستیم؛ سقف بازار برای بسته‌های پریمیوم خالی است.
```

## گام ۳ — یادداشت تصمیم

```markdown
# یادداشت: {موضوع}

تاریخ: {تاریخ} | نویسنده: پژوهشگر

## مسئله

یک پاراگراف.

## شواهد

- رقیب A قیمت اشتراک را ۲۰٪ کم کرد ([لینک]، مشاهده ۱۴۰۵/۰۷/۲۰)
- ۳ تیکت درباره‌ی «قیمت بالا» در ۱۴ روز

## گزینه‌ها

۱. ثابت بمانیم — ریسک: از دست دادن خریدار حساس به قیمت
۲. بسته‌ی ورودی ارزان‌تر — ریسک: کاهش میانگین سبد
۳. افزودن ارزش (بازبینی سریع) — ریسک: بار عملیاتی

## توصیه

گزینه ۳، با بازبینی در ۳۰ روز.

## ریسک وابسته

اگر رقیب A تبلیغ کند، تفاوت قیمت دیده می‌شود.
```

## گام ۴ — به‌روزرسانی roadmap

اگر یافته تغییر اولویت می‌دهد، پیشنهاد دقیق بده:

```text
docs/roadmap.md → فاز R2 → افزودن: «بسته‌ی ورودی دسته‌ی ویدیو»
دلیل: شواهد بالا | تلاش تخمینی: ۲ روز
```

تغییر را خودت اعمال نکن؛ پیشنهاد بده.

## خروجی

- یک یادداشت ≤ ۵۰۰ کلمه
- جدول قیمت ۵ رقیب
- حداکثر سه پیشنهاد

## ممنوعیت‌ها

- ادعای بی‌منبع یا «شنیده‌ام».
- جمع‌آوری داده‌ی شخصی.
- ورود به حساب کاربری دیگران.
- توصیه‌ی حقوقی یا مالی.
- کپی متن رقیب.
