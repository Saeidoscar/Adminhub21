# گزارش رشد هفتگی

## قانون

هر عدد باید منبع داشته باشد. اگر منبع نداری، بنویس `نامعلوم` — عدد نگذار.

## گام ۱ — جمع‌آوری

منابع مجاز:

- Analytics (Plausible/Vercel) — ورودی، منبع، صفحه
- `GET {API}/admin/dashboard/stats` — کاربر، بسته، سفارش، درآمد
- `GET {API}/admin/users?per_page=1` (فقط شمارش)
- GitHub Releases / `CHANGELOG.md` — محتوای واقعی برای نوشتن

```text
ورودی: ۴٬۲۰۰ (+۱۲٪)
منبع: جستجو ۵۵٪ | مستقیم ۲۵٪ | اجتماعی ۲۰٪
ثبت‌نام: ۸۴ (نرخ تبدیل ۲.۰٪)
خرید: ۱۱ (نرخ تبدیل ثبت‌نام ۱۳٪)
درآمد: ۴۸٬۵۰۰٬۰۰۰ تومان
پرهزینه‌ترین کانال: — (تبلیغ پولی فعال نیست)
```

## گام ۲ — تحلیل

سه پرسش را جواب بده، هر کدام در یک پاراگراف کوتاه:

1. چه چیزی رشد کرد و چرا؟ (با عدد)
2. چه چیزی افت کرد؟ (با عدد و فرضیه)
3. کدام صفحه بیشترین خروج داشت؟

## گام ۳ — محتوا

تقویم هفته: **۱ تکه‌ی اصلی + ۳ پست کوتاه**.

منابع مجاز برای موضوع:

- بسته‌های پرتقاضای بازار
- تغییرات محصول در `CHANGELOG.md`
- سؤال‌های تکراری تیکت‌ها (بدون داده‌ی شخصی)
- یادداشت پژوهشگر

برای هر تکه:

```text
عنوان: «قیمت واقعی ادیت ویدیو در ۱۴۰۵»
نوع: راهنما | ~۹۰۰ کلمه
منبع داده: ۱۲ بسته‌ی دسته‌ی ویدیو، میانگین ۸۵۰٬۰۰۰ تومان
لینک داخلی: /marketplace?category=video، /pricing
کلمه‌ی کلیدی: قیمت ادیت ویدیو
CTA: «بسته‌ها را مقایسه کن»
```

**قواعد نوشتار:** فارسی محاوره‌ی رسمی، جمله‌های کوتاه، بدون «ما بهترینیم»،
بدون «تضمین رتبه»، بدون عدد بی‌منبع. لحن در `write-like-a-person`.

## گام ۴ — سئو

- عنوان ≤ ۶۰ کاراکتر، توضیح ۱۴۰–۱۶۰.
- یک `h1`، زیرعنوان‌های `h2` واقعی.
- لینک به حداقل دو صفحه‌ی داخلی مرتبط.
- تصویر با `alt` توصیفی.
- Schema فقط اگر داده‌ی واقعی دارد (Product/FAQ).

## گام ۵ — گزارش

```text
رشد — هفته‌ی {تاریخ}
KPI: ورودی ۴٬۲۰۰ (+۱۲٪) | ثبت‌نام ۸۴ | خرید ۱۱
بهترین صفحه: /marketplace/video-editing (۳۲۰ ورودی، ۱۸٪ تبدیل)
ضعیف‌ترین: /pricing (خروج ۶۲٪)
محتوا: ۱ راهنما + ۳ پست آماده‌ی تأیید
اقدام پیشنهادی هفته‌ی بعد: افزودن مقایسه‌ی قیمت به صفحه‌ی دسته
```

## ممنوعیت‌ها

- انتشار بدون تأیید.
- ادعای عددی بدون منبع.
- مقایسه‌ی توهین‌آمیز با رقبا.
- وعده‌ی درآمد، رتبه یا نتیجه‌ی تضمینی.
- خرید فالوور، تبلیغ در کانال‌های مشکوک، یا ارسال انبوه.
