## R3 — زیرساخت ایران (وقتی اولین مشتری پرداخت کرد)

**هدف:** از دموی لوکال به سرویس واقعی، روی ابری که از ایران در دسترس است.

### پیشنهاد شروع — حدود ۴٬۵ میلیون تومان در ماه

| سرویس | مشخصات | ماهانه (تومان) |
| --- | --- | --- |
| Cloud Server | ۲ vCPU / ۴GB / ۶۰GB SSD | ۲٬۴۹۱٬۴۰۰ |
| CDN | پلن Base | ۰ |
| Object Storage | پلن Growth (۵۰۰GB / ۲TB) | ۱٬۵۰۰٬۰۰۰ |
| AIaaS | ~۲ میلیون تومان مصرف | ۱٬۹۸۷٬۲۰۰ |
| **جمع** | | **≈ ۴٬۴۸۰٬۰۰۰** |

در این مرحله **DBaaS و صف مدیریت‌شده نمی‌گیریم**: PostgreSQL و Redis روی همان
VM با Docker بالا می‌آیند و بکاپ روزانه به Object Storage می‌رود. این ارزان‌ترین
ترکیب قابل‌قبول است و برای ترافیک اول کافی.

### پیشنهاد رشد — حدود ۹٬۴ میلیون تومان در ماه

| سرویس | چرا |
| --- | --- |
| VM اپ (۲/۴/۶۰) + VM کارگر (۱/۲/۴۰) | جدا کردن Horizon از وب |
| DBaaS Starter | بکاپ و بازگردانی مدیریت‌شده |
| Object Storage Growth | رسانه‌ی بسته‌ها |
| AIaaS | دستیار هوشمند |
| **جمع** | **≈ ۹٬۴۴۰٬۰۰۰** (با standby: ۱۰٬۷۳۰٬۰۰۰) |

- [ ] انتقال دیتابیس و تست بازیابی
- [ ] بکاپ خودکار + تمرین restore
- [ ] Cloud Logs و هشدار ۵xx
- [ ] صف Horizon روی VM جدا
- [ ] CDN روی دامنه و کش تصاویر

**معیار خروج:** یک بازیابی کامل از بکاپ روی محیط staging انجام شده باشد.
تا وقتی restore را تمرین نکرده‌اید، بکاپ ندارید.

**نکته‌های تأییدشده‌ی آروان:** Redis مدیریت‌شده ندارد؛ ایمیل تراکنشی روی
پورت ۲۵/۴۶۵ بسته است (SMTP بیرونی لازم است)؛ APM ندارد (Cloud Logs + Sentry).
