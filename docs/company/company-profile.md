# AdminHub21 — معرفی شرکت

> بازار متخصصان محتوا، ابزار و قرارداد؛ با قیمت شفاف، قرارداد الکترونیکی و
> کیف پول یکپارچه.

---

|                 |                                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------------------- |
| **نام**         | AdminHub21                                                                                                          |
| **چه می‌کند**    | بازار دوطرفه‌ای که کارفرما را به متخصص تأییدشده وصل می‌کند و کل مسیر را تا قرارداد، تحویل و تسویه در یک جا نگه می‌دارد |
| **برای چه کسی** | کسب‌وکارهای کوچک و متوسط فارسی‌زبان که محتوا، طراحی، سئو یا ابزار می‌خرند                                              |

## ۲) مشکلی که حل می‌کنیم

خرید خدمات محتوایی در بازار فارسی امروز سه درد دارد:

1. **قیمت نامعلوم.** مشتری نمی‌داند «مدیریت اینستاگرام» باید چقدر باشد، پس
   مذاکره جای قیمت شفاف را می‌گیرد.
2. **تعهد نامکتوب.** توافق در دایرکت و واتساپ می‌ماند؛ نه دامنه‌ی تحویل مشخص
   است، نه راهی برای پیگیری.
3. **پول بی‌صاحب.** پرداخت مستقیم به متخصص، ریسک بدحسابی و فرار از تعهد را
   برای هر دو طرف می‌سازد.

AdminHub21 هر سه را در یک مسیر جمع می‌کند: **بسته‌ی قیمت‌گذاری‌شده → قرارداد
الکترونیکی → کیف پول → تحویل → تسویه**. چیزی که در دایرکت شروع می‌شد، حالا
قابل استناد است.

## ۳) محصول

| سطح           | چه چیزی                                          | وضعیت                      |
| ------------- | ------------------------------------------------ | -------------------------- |
| بازار عمومی   | جستجو، فیلتر دسته/قیمت، صفحه‌ی بسته، سئوی هر بسته | ✅ منتشرشده                |
| پروفایل متخصص | تأییدشده، نمونه‌کار، امتیاز                       | ✅                         |
| قرارداد       | ساخت، امضا، خروجی PDF                            | ✅                         |
| کیف پول       | شارژ، برداشت، تراکنش، تأیید ادمین                | ✅                         |
| پشتیبانی      | تیکت، یادداشت داخلی، اولویت، ارجاع               | ✅                         |
| ادمین         | آمار، کاربران، دسته‌بندی، صف تیکت                 | ✅                         |
| دستیار هوشمند | چت با مدل‌های زبانی                               | ✅ (آماده‌ی اتصال به AIaaS) |

**معماری:** Next.js 16 برای سایت و فضای کاری، Laravel روی PHP 8.4 برای API،
PostgreSQL و Redis، همه در Docker. مرورگر هیچ‌وقت مستقیم با API حرف نمی‌زند؛
توکن در کوکی `httpOnly` می‌ماند.

**اعتبار مهندسی (قابل بررسی در مخزن):** ۱۷۲ مسیر API، ۸۴ تست خودکار، سه نقش
دسترسی، ۴۹ migration، CI روی PostgreSQL 16 و PHP 8.4.

## ۵) چرا ما

- **کل مسیر، نه یک تکه از آن.** رقبا یا فقط دایرکتوری‌اند یا فقط قرارداد
  می‌سازند. ما از کشف تا تسویه یک سیستم هستیم.
- **شفافیت قیمت.** هر بسته قیمت و دامنه‌ی تحویل دارد؛ مقایسه ممکن است.
- **پول در کیف پول می‌ماند تا تحویل.** این هم برای کارفرما اطمینان است، هم
  برای متخصص تعهد.
- **ساخت ایران، آماده‌ی مقیاس.** روی زیرساخت داخلی (ابر آروان) اجرا می‌شود،
  با درگاه‌های ایرانی، بدون وابستگی به سرویسی که از ایران در دسترس نیست.

## ۶) مدل عملیاتی

شرکت عمداً کوچک است: **یک بنیان‌گذار + هفت کارمند هوش مصنوعی**.

| لایه   | چه کسی                                                        | اختیار                                  |
| ----- | ------------------------------------------------------------- | --------------------------------------- |
| تصمیم | بنیان‌گذار                                                     | قیمت، استخدام، انتشار، پول              |
| اجرا  | کارمندان AI (پشتیبانی، بازار، مالی، انتشار، رشد، پژوهش، ستاد) | پیش‌نویس، تحلیل، پیگیری، گزارش           |
| تأیید | بنیان‌گذار یا مالک فرایند                                      | پرداخت، قرارداد، انتشار عمومی، حذف داده |

جزئیات در [`organization.md`](organization.md). هزینه‌ی این تیم، مدل و مهارت‌ها
در [`../operations/opencompany.md`](../operations/opencompany.md).

## ۷) اصول کار

1. **شفاف باش.** قیمت، وضعیت تیکت، تاریخ انتشار — همه قابل دیدن.
2. **پول را آدم تأیید می‌کند.** هیچ عامل خودکاری پرداخت نمی‌کند.
3. **کوچک بفرست، سریع درست کن.** انتشار هفتگی بهتر از انتشار کامل.
4. **هر تصمیم یک سند دارد.** changelog، runbook، این دفتر.
5. **داده‌ی مشتری امانت است.** حداقل دسترسی، حداقل نگهداری، حداقل اشتراک.
