# دفتر شرکت — AdminHub21

این پوشه «شرکت» را تعریف می‌کند، نه محصول را. هر چیزی که یک همکار تازه، یک
سرمایه‌گذار، یک مشتری سازمانی یا یک کارمند هوش مصنوعی برای فهمیدن AdminHub21
لازم دارد، اینجاست.

| سند                                                            | برای چه کسی             | چه چیزی می‌گوید                                  |
| -------------------------------------------------------------- | ----------------------- | ----------------------------------------------- |
| [`company-profile.md`](company-profile.md)                     | مشتری، شریک، سرمایه‌گذار | ما کی هستیم، چه می‌فروشیم، چطور پول درمی‌آوریم    |
| [`organization.md`](organization.md)                           | بنیان‌گذار               | ساختار تیم، KPI ها، مرزهای تصمیم، ترتیب استخدام |
| [`employees/`](employees/)                                     | بنیان‌گذار + OpenCompany | شرح شغل و brief استخدام هر کارمند هوش مصنوعی    |
| [`hiring-briefs.md`](hiring-briefs.md)                         | OpenCompany (Home)      | متن‌های آماده‌ی کپی برای استخدام هر نقش           |
| [`one-pager.html`](one-pager.html)                             | چاپ / PDF               | معرفی یک‌صفحه‌ای برند برای جلسه و ایمیل           |
| [`../operations/opencompany.md`](../operations/opencompany.md) | بنیان‌گذار               | نصب، اتصال مدل، هزینه، امنیت، ترتیب راه‌اندازی   |

پوشه‌ی ماشین‌خوان در ریشه‌ی مخزن است:

```
.opencompany/skills/<skill-name>/SKILL.md   ← مهارت‌های آماده‌ی بارگذاری
```

OpenCompany مهارت‌ها را از `.opencompany/skills` در ریشه‌ی پروژه می‌خواند
(تأییدشده در `server/services/skill_loader.py`). اگر `company start` را از ریشه‌ی
همین مخزن اجرا کنید یا این پوشه را به‌عنوان workspace باز کنید، مهارت‌ها
خودکار در کتابخانه‌ی شرکت ظاهر می‌شوند.

## قاعده‌ی طلایی

> هر کارمند هوش مصنوعی **پیشنهاد** می‌دهد؛ **پول، قرارداد، انتشار عمومی و حذف
> داده** را انسان تأیید می‌کند. این قاعده در همه‌ی اسناد تکرار شده و در
> بخش «مرزها»ی هر نقش صریح آمده است.
