## 📖 Overview

Dadline is a modern AI-powered legal platform designed to simplify legal services for citizens, lawyers, law firms, and organizations.

### Key Features

- 🤖 AI-powered legal assistant
- ⚖️ Online legal services
- 👨‍⚖️ Lawyer directory
- 📂 Case management
- 📄 Secure document storage
- 💳 Payment gateway
- 🔄 Digital legal workflows

# 🚀 Quick Start

## Clone Repository

```bash
git clone git@github.com:dadline/dadline.git
```

```bash
cd dadline
```

---

## Environment

```bash
cp .env.example .env
```

---

## Start Infrastructure

```bash
docker compose up -d
```

---

## Install Dependencies

### Frontend

```bash
pnpm install
```

### Backend

```bash
composer install
```

---

## Database

```bash
php artisan migrate
```

---

## Start Development

```bash
pnpm dev
```
